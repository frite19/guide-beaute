## 1. Priorité 1 — une revendication de test qui n'a jamais eu lieu

### Pin Maybelline Fit Me — 73 impressions

**Description actuelle (en ligne) :**
> `Photo is illustrative. Testing the Maybelline Fit Me Shine-Free + Balance foundation stick - it is a cream stick, not a liquid. Does the matte finish work on dry skin? Honest verdict...`

Le mot **« Testing »** annonce un test. Il n'y a pas eu de test. C'est le seul pin du compte
dans ce cas (contrôle fait sur les 30 pins le 15/11 : aucune autre occurrence de
« tested / testing / hands-on / tried it »).

**Nouvelle description :**
```
Photo is illustrative. Maybelline Fit Me Shine-Free + Balance is a cream foundation stick with a natural matte finish, applied straight from the tube in thin, buildable layers and usable a second time as a contour stick. No SPF is claimed. On bare dry skin the matte finish can read flat, so it needs a hydrated base first. Some links on this page are affiliate links. #makeup #dryskin #maybelline
```

Vérifié sur la page `/product/fit-me-shine-free-balance-stick/` : « cream foundation stick »,
« natural matte finish », « applied straight from the tube in thin, buildable layers »,
« usable a second time as a contour stick », « No SPF is claimed », « On bare dry skin the matte
finish can read flat ». **Chaque phrase de la description existe mot pour mot sur la page.**

- **Lien à ne pas toucher :** `/product/fit-me-shine-free-balance-stick/`

## 3. Priorité 3 — un pin à supprimer (59 impressions)

**Pin concerné :** `https://www.pinterest.com/pin/1115133557770769453/`
**Destination :** `/comparisons/best-hot-air-brush-2026/` · **Tableau :** Hot Air Brush · **Titre :** aucun

**Ce que montre le visuel :** une femme debout tenant un **sèche-cheveux bleu classique**,
avec le texte incrusté :

> **Revlon One-Step Review**
> Worth It? Honest USA Test

Deux problèmes, et aucun ne se corrige par une édition :

1. **« Honest USA Test »** annonce un test qui n'a jamais eu lieu. Le texte est **dans l'image** :
   changer le titre ou la description ne le retire pas.
2. **L'appareil photographié n'est pas un Revlon One-Step.** Le One-Step est un sèche-cheveux à
   brosse ovale intégrée ; sur l'image, c'est un sèche-cheveux à buse ronde. Le pin promet un
   produit qu'il ne montre pas.

**Recommandation : supprimer.** 59 impressions sur le mois, aucune perte de référence, et le pin
est le seul du compte à revendiquer un test en image.

> ⚠️ **Attendre l'accord de Farid.** La suppression est définitive.

## 5. Mode opératoire d'une correction

1. Pinterest → le pin → **Modifier le pin**.
2. Ne toucher **que** le champ concerné (titre ou description).
3. **Ne jamais** modifier le champ « Lien ».
4. Enregistrer, puis vérifier par le flux RSS du tableau que le nouveau texte est bien en place.
5. Une correction par pin et par 24 h. Deux maximum.

**Rythme conseillé :** 2 corrections par jour, en plus du pin du jour, sur trois jours.
Ne pas tout faire d'un coup : Pinterest limite les modifications en rafale.
