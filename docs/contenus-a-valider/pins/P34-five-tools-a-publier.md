### Pourquoi cet angle

Cinquième destination outils jamais pinnée. L'angle est la réponse à la question que se pose
une débutante devant un set : est-ce que cinq outils suffisent ? La page y répond outil par
outil, et nomme elle-même les deux manques. C'est une règle d'usage, pas une promesse.

### Note sur le choix du produit taggé

Le produit taggé est celui de la page. La fiche dit aussi ce qui manque (pinceau concealer,
pochette) : le pin ne promet donc pas un set complet.
